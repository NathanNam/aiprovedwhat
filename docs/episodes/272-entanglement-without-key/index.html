Entangled, but no secret?

An AI preprint claims an entangled state with zero distillable key, and a counterexample to the PPT-squared conjecture

The claim, in plain words

Alice and Bob want a secret key that an eavesdropper, Eve, cannot know. Shared entangled pairs, measured the same way on both sides, give matching random bits that no one else can predict, and every secret key of this kind needs entanglement. The question is whether every entangled state can give some key.

Some entanglement is hard to see. The standard test flips one side, a partial transpose: for a perfectly entangled pair it gives a negative eigenvalue of −1/2. But in the late 1990s Paweł Horodecki found entangled states that pass this test, and the Horodeckis called them bound entangled, because no pure entanglement can be distilled from them. Surprisingly, in 2003 three Horodeckis and Oppenheim showed that some of these still give secret key. Whether every entangled state gives key went on a 2005 list of open problems as Problem 24, and a 2018 paper still called it widely open. A second question, asked by Christandl in 2012, is whether two channels in a row, each passing the partial transpose test, must always destroy entanglement.

Result 272 is one OpenAI preprint, 53 pages, dated September 27, 2026. It constructs an explicit entangled state of two ten-level systems that passes the partial transpose test, and from which no secret key can be distilled by a wide class of protocols: local quantum operations on any number of copies, two-way public communication, and an eavesdropper holding a purification and every public message. Any output bit stays at least a fixed distance from an ideal secret bit. The same construction gives counterexamples to the partial-transpose-squared question: two explicit maps on ten levels, each passing the test, whose composition still carries entanglement, and a single channel on 21 levels whose square does. The state is exactly the Choi matrix of that composition, scaled to trace one.

What it doesn’t claim

That bound entanglement never gives key, which is false; protocols outside the admitted class; or the smallest dimension where this happens. In dimension three, Christandl’s conjecture was already proved true.

How the proof goes

  1. Twenty special directions. The entanglement proof starts from an integer 6×4 matrix pencil with exactly 20 special directions (all real, by our computation). With Galois theory and arithmetic modulo three primes, the paper shows that no quadric passes through ten of them. A product vector in the range would need two quadrics covering all twenty, but two catch at most eighteen, so the state must be entangled. Standard numerical tests miss it: our realignment value is 0.54, below the threshold of 1.
  2. The one-fifth wall. The key side uses a four-effect inequality: being secret needs coherence between the both-zero and both-one outcomes, and for these states, being correct forbids it. The two bounds cross exactly at 1/5, so in the paper’s measure no protocol gets closer than 1/5 to a perfect secret bit.

The numbers in the video

  • Ours: the partial transpose of a perfectly entangled pair has eigenvalue −1/2.
  • Ours: the paper’s 100×100 Choi matrix rebuilt: rank 80, passes the partial transpose test, trace 130,208,350,782; realignment value 0.54.
  • Ours: the two bounds of the key argument cross exactly at 1/5, with value 2/5.
