Result 130 · Theoretical computer science

Exact Fourier transforms below nlog⁡nn\log nnlogn

OpenAI’s summary

Gives a deterministic length-n discrete Fourier transform algorithm using O(n(log⁡n)1−δ)O(n(\log n)^{1-\delta})O(n(logn)1−δ) operations for every n, with explicit δ=10−13\delta=10^{-13}δ=10−13. The model uses exact complex arithmetic, unrestricted coefficients and a supplied root of unity, and counts scalar preparation and logarithmic-word indexing.
