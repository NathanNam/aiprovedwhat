A quasilinear PCP theorem for PPAD

OpenAI’s summary

Resolves the quasilinear PCP-for-PPAD conjecture. An End-of-Line instance of length N reduces to numerical circuit constraints of total length N(log⁡N)O(1)N(\log N)^{O(1)}N(logN)O(1) such that any polynomially encoded rational assignment satisfying all but a fixed fraction to fixed accuracy yields an endpoint solution. Such assignments always exist, giving robust local verification with only quasilinear size overhead.
