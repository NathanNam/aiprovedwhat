Strongly polynomial-time linear programming

OpenAI’s summary

A deterministic algorithm solves linear programs with arbitrary real coefficients in a number of steps polynomial in the numbers of variables and constraints, answering Smale’s ninth problem. Bounded simple rational polytopes can have graph diameter superpolynomial in their facet count, refuting the polynomial Hirsch conjecture. For any prescribed subpolynomial bound on face dimension, the examples can be chosen so that even moves across such faces require superpolynomially many steps.
