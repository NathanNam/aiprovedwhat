Exact derandomization of logarithmic space: L=RL=BPL\mathsf L=\mathsf{RL}=\mathsf{BPL}L=RL=BPL

OpenAI’s summary

Proves L=RL=BPL\mathsf L=\mathsf{RL}=\mathsf{BPL}L=RL=BPL, resolving derandomization for bounded-error logarithmic-space computation. An effective compiler converts each randomized polynomial-time logarithmic-space machine deciding a language with one-sided or two-sided error into a deterministic logarithmic-space decider with explicit polynomial running-time bounds.
