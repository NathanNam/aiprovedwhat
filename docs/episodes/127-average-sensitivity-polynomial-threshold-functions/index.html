Average sensitivity of polynomial threshold functions

OpenAI’s summary

Proves that a degree-at-most-d polynomial threshold function on the uniform n-dimensional Boolean cube has average sensitivity at most 8dn8d\sqrt n8dn​, uniformly for 1≤d≤n1\le d\le n1≤d≤n. Average sensitivity counts expected output changes under single-bit flips. This establishes the asymptotic Gotsman–Linial conjecture, allowing polynomial zeros with sign(0)=1\mathop{\mathrm{sign}}\nolimits (0)=1sign(0)=1.
