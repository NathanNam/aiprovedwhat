Result 372 · Partial differential equations

Global uniqueness in smooth isotropic elasticity

OpenAI’s summary

Proves that full static boundary displacement-to-traction data determine both smooth real Lamé moduli on every bounded connected smooth domain in ℝ3, provided μ > 0 and 3λ+2μ>03\lambda+2\mu\gt 03λ+2μ>0 on the closure. Neither analyticity, proximity to constant coefficients nor prior knowledge near the boundary is required.
