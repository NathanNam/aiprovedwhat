Result 292 · Operator algebras

Kirchberg's O2\mathcal O_2O2​ norm-ultrapower embedding problem

OpenAI’s summary

Constructs an explicit separable unital full group C∗-algebra that cannot embed unitally into the norm ultrapower of any fixed nonzero unital nuclear C∗-algebra, for any free ultrafilter on the natural numbers. Taking the target to be O2\mathcal O_2O2​ answers Kirchberg's norm-ultrapower embedding problem negatively.
