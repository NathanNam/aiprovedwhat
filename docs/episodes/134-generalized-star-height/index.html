The claim, in plain words

Regular expressions build languages, sets of words, from letters with union, concatenation and the Kleene star, and star height counts how deeply the stars are nested. Generalized expressions also allow complement over the same alphabet, which costs nothing in height and can make stars unnecessary: (ab)* is exactly the set of words that do not start with b, do not end with a, and contain no doubled letter, with no star at all. Some languages do need a star, such as the words of even length over one letter.

Without complement, Eggan tied star height to the cycles of automata, and Dejean and Schützenberger showed it is unbounded even over two letters. With complement, height zero means star-free, which Schützenberger characterized by aperiodic monoids. Henneman showed one star suffices for languages recognized by finite abelian groups, as Pin, Straubing and Thérien recall, and they added more families. No language was known to need two stars, and Straubing stressed that a universal bound and a bound of one are different questions.

Result 134 is three OpenAI preprints, 116 pages dated September 25, 2026, each with its own complete proof. Every regular language over a finite alphabet has a generalized expression over that same alphabet with at most thirteen (44 pages), four (34 pages) and three (38 pages) nested stars. The bound does not depend on the alphabet, the language or the automaton. The construction never adds letters: as one companion paper notes, by results of Pin, Straubing and Thérien, if height bounds survived replacing letters by whole words, one star would already suffice.

What it doesn’t claim

That three is optimal: no language is shown to need two stars, so the true worst case is one, two or three. The papers bound only the nesting, not the size of the expressions or the time to build them, which can be enormous.

How the proof goes

  1. Monoids and episodes. Running an automaton turns each word into a map of states; these maps form a finite monoid, and it suffices to describe the words with a given product. Words are cut into episodes, pieces of a prefix code ending a fixed distance after a marker or after a periodic stretch first breaks, so each episode is bounded data, at most one long periodic run and a bounded tail. Powers in a finite monoid eventually repeat, so the run lengths that matter are eventually periodic: one star.
  2. Splits and a clock. An episode is cut into a prefix test for the incoming state and a suffix test for the outgoing one, and one star repeats this along the word; each split costs a star. The two sides share only where the cut falls, so a clock lets each measure its distance to the cut; once an end guard makes them agree on the end, the sum is the episode’s own. Either the sides agree or exactly one disagreeing pair remains, absorbed by an affine correction that costs nothing, since comparing with a run from zero cancels it by unions and intersections.
  3. A shift table. The block straddling the cut cannot be read in full by either side. A shift table, one tuple length for every table of maps with a correction chosen per table, ensures that some coordinate can change without changing the result, so the hidden block never needs to be known; random corrections work with positive probability by the Erdős–Lovász local lemma.
  4. Where the three stars go. The three-star paper needs two splits: an outer split over all episodes, skipping those where the clock or marker searches fail, and an inner split over those, with copies of the information at spaced positions so one can always be decoded. Periodic runs give the first star, the inner split the second, the outer split the third. The thirteen-star paper used twelve splits, the four-star paper three.

The numbers in the video

  • (ab)* and its star-free description agree on all 32,767 words over two letters up to length 14.
  • Counting a’s modulo 3: the usual expression nests two stars; writing each run of b’s with a complement leaves one (checked on every word up to length 12).
  • Transition monoids: (ab)* and “contains aa” are aperiodic (star-free); (aa)* and counting modulo 3 are not.
  • The smallest nontrivial shift table (two symbols, a one-bit state): length 3 works for every table, lengths 1 and 2 fail for some (2 of 4 and 8 of 16 tables); the paper’s general estimate would need length 13.

2:46How the proof goes

All three proofs start from a finite monoid. Run an automaton on a word and record the resulting map from states to states. These maps form a finite monoid, and the language is a union of the sets of words with a given product, so it suffices to describe each of those sets. The proofs cut each word into episodes, pieces from a prefix code so that the cutting is unique. An episode ends by a local rule: a fixed distance after a marker pattern, or else a fixed distance after a periodic stretch first breaks. So each episode is bounded data, at most one long periodic run, and a bounded tail. Powers of a monoid element eventually repeat, so the run lengths that matter form an eventually periodic set, written with one star. That is the first star. To string episodes together, the proof cuts an episode in two: a prefix test for the incoming state and a suffix test for the outgoing one. One star repeats this along the word, passing over skipped episodes. Each split costs one star. The trouble is that a prefix and a suffix are separate pieces of a concatenation: the only thing they share is where the cut falls. So the proof uses a clock. The prefix measures one distance to the cut and the suffix another, and once an end guard makes both sides agree on where the episode ends, their sum is fixed by the episode itself. The sets are built so that either the two sides agree, or there is exactly one disagreeing pair, which an affine correction absorbs. Corrections are free: comparing the run from the real input with a run from zero cancels the translation, using only unions and intersections. The remaining obstacle is the one block of the word that straddles the cut, which neither side can read in full. A shift table handles it: with one tuple length that works for every table of maps, a fixed correction is chosen for each table, such that for every tuple and every input, some coordinate can change without changing the result. Then the hidden block never needs to be known. For long enough tuples, a random correction works with positive probability, by the Erdős–Lovász local lemma. In our check, in the smallest nontrivial case, two symbols and a one-bit state, length three works for every table, while lengths one and two fail for some; the paper’s general estimate would need length thirteen. With these tools, the three-star paper needs only two splits. The outer split, over all episodes, skips those where the clock or the marker searches fail. The inner split, over those, places copies of the information at carefully spaced positions so that one copy can always be decoded. Periodic runs give the first star, the inner split the second, and the outer split the third. The thirteen-star paper used twelve splits, and the four-star paper used three.

5:40Where it stands

The three preprints are not peer reviewed and have not been revised. The Lean formalization covers the bound of three; we have not run it. None of these papers is among those OSVerify reviewed, and we have seen no expert review. If it holds, three nested stars, together with complement over the same alphabet, are enough for every regular language, answering the uniform boundedness question. Whether one star always suffices is still open, so the answer now is one, two or three.
