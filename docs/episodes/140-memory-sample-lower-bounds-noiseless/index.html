Memory–sample lower bounds for noiseless Gaussian regression

OpenAI’s summary

For fixed A > 0, a one-pass learner with Ad2Ad^2Ad2 persistent bits needs ΩA(dlog⁡(1/ϵ))\Omega_A(d\log(1/\epsilon))ΩA​(dlog(1/ϵ)) noiseless Gaussian samples to recover a unit vector to angular error 0<ϵ≤1/100\lt \epsilon\le1/100<ϵ≤1/10 with probability 2/3, uniformly in accuracy for large d. Computation and randomized updates are unrestricted, but output uses only the terminal state, stopping index and fresh randomness.
