Result 184 · Combinatorics

Correspondence coloring with a fixed forbidden subgraph

OpenAI’s summary

Proves the Alon–Krivelevich–Sudakov coloring conjecture in correspondence-coloring form: graphs avoiding any fixed subgraph F need OF(Δ/log⁡Δ)O_F(\Delta/\log\Delta)OF​(Δ/logΔ) colors when their maximum degree Δ is sufficiently large. Also proves the Ajtai–Erdős–Komlós–Szemerédi independence conjecture: for fixed r ≥ 4, every n-vertex Kr-free graph of average degree d ≥ 2 has an independent set of size Ωr(nlog⁡d/d)\Omega_r(n\log d/d)Ωr​(nlogd/d).
