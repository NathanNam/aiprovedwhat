Beyond the square-root exponent for depth-three circuits

OpenAI’s summary

Constructs a single language in deterministic polynomial time whose n-bit membership function requires 2ω(n)2^{\omega(\sqrt n)}2ω(n​) total gates in unbounded-fan-in OR–AND–OR circuits, at every sufficiently large input length. This crosses the square-root-exponent threshold for explicit depth-three Boolean circuit lower bounds.
